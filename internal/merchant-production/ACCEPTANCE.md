# Direct merchant conformity
The same Worker and D1/R2 implement direct confirmation of the exact verified signed contract and exact current profile. An authorized representative generates a 256-bit code, delivers it through a previously verified channel and logs the delivery reference. Only its hash is persisted. The code expires after 24 hours, can be revoked, is submitted by POST, and is consumed once. The browser uses a Secure HttpOnly SameSite cookie; no code in URL. Merchant reviews the exact document or profile, confirms or requests corrections. Production still requires administrator document verification, administrative profile approval and direct merchant conformity before readiness. This is an acknowledgement of a signed contract, not qualified digital signature, automated signing, or independently verified legal identity. Provider-free manual delivery is intentional; no email subscription. Existing launch gate remains closed. Real security/runtime and legal review are outstanding; migration v8 not yet applied. No public launch.
