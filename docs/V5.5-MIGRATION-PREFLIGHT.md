## BLOQUEO TÉCNICO CRÍTICO — NO copiar Prime y desplegar directamente

El repo oficial posee un **sello visual deliberado**: `config/visual-baseline-approved.json` tiene `baseline_id=DESSET-V12-CONTACT-2026-11-17`, hashes Git de HTML/CSS/JS y assets; `scripts/approved-baseline-gate.mjs` verifica los archivos protegidos.

El workflow `.github/workflows/cloudflare-pages-production.yml` en el repo oficial:
1. **Solo se dispara por `workflow_dispatch` desde `main`**, con confirmación literal `PUBLICAR_DESSET`.
2. Ejecuta instalación reproducible, `npm run check`, auditorías de seguridad, cobertura, mutation smoke, Chrome, paquetes y **gates de Cloudflare**.
3. Construye un artefacto de producción con inventario cerrado de **13 archivos**. Prime contiene más assets y rutas nuevas; el empaquetador, allowlist, rutas y pruebas deberán evolucionar **mediante un PR de integración separado**.
4. **Exige aprobación específica del diseño** mediante un comentario de cuenta propietaria en un issue del repo `M0-coder/DESSET` que incluya el SHA256 del manifiesto propuesto, conforme a `docs/VISUAL-CHANGE-01.md`.
5. El despliegue al proyecto `desset-institucional` es una acción **separada**, con controles y verificación posterior, no implícita en CI verde.

El PR Prime NO pasa automáticamente ninguno de esos procesos. No desactivar ni debilitar los gates existentes para promover el rediseño.

## Secuencia correcta para una autorización futura

1. **Cerrar revisión visual humana** Figma maestro y variantes; obtener dictamen firmado del fundador sobre la identidad y los renderizados, con derechos comerciales rastreados.
2. **Cerrar pruebas reales:** Android modesto + iOS/desktop cuando aplique, 320/390/768/1440, zoom 200/400 %, teclado/lector de pantalla, red 4G, movimiento reducido, métricas de campo LCP/INP/CLS. Lighthouse de CI no reemplaza estas mediciones.
3. **Cerrar claims y canales:** revisar Instagram, X y Facebook, situación societaria/propiedad intelectual, ausencia de supuestos clientes/operaciones.
4. **Definir port técnico:** crear nuevo PR en `M0-coder/DESSET` exclusivamente tras autorización explícita, incorporando **un snapshot fijado por SHA de Prime**, preservando assets originales y ajustando scripts de empaquetado, allowlists, `_headers`, pruebas, canonical/indexación y CSS.
5. **Visual change gate:** generar propuesta de hashes y cumplir el procedimiento de `VISUAL-CHANGE-01.md` mediante comentario verificable del propietario, **no** editando o esquivando el gate.
6. **Release-candidate CI oficial:** ejecución real completa, CodeQL, SBOM si corresponde, coverage, mutation smoke, pruebas negativas, navegador, paquete Cloudflare y aprobación de revisión independiente.
7. **Preflight de producción SOLO LECTURA justo antes de actuar:** reconsultar Cloudflare proyecto, última implantación y DNS/dominios; guardar SHA/ID del estado anterior y la comparación de rollback; no reutilizar los datos de este documento como si fueran actuales.
8. **Autorización por SHA exacto** para merge al repositorio oficial, por separado de una autorización posterior y explícita para ejecutar publicación manual, manteniendo DNS sin cambios salvo instrucción separada.
