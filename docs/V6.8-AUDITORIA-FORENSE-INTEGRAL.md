# DESSET PRIME V6.8 — AUDITORÍA FORENSE INTEGRAL / NO PUBLICACIÓN

**Alcance autorizado:** exclusivamente `M0-coder/DESSET-prime`, PR #2 Draft, rama experimental. **NO MERGE, NO DEPLOY, NO RELEASE, NO DNS, NO cambios en `M0-coder/DESSET`**.

**Criterio rector:** Primero fija el alcance: arquitectura, compilación, pruebas unitarias e instrumentadas, cobertura, análisis estático, calidad de CI, seguridad, reproducibilidad, mutation testing, deuda técnica y evidencia de ejecución.

Una auditoría, incluso exhaustiva en código, **no puede garantizar que no existan errores**. Este documento separa hallazgos comprobados, soluciones implantadas, pruebas ejecutadas y riesgos que requieren evidencia futura.

## A. Inventario verificado

- Web informativa estática: seis secciones, menú progresivo, HTML semántico, dos hojas heredadas y una hoja de sistema visual (V6.7).
- Render inicial WebP para móvil/escritorio; Three.js WebGL2 `0.187.0` solo por acción explícita, bundle compilado con esbuild `0.28.2`; tres GLB propios.
- Build `npm ci --ignore-scripts`, `npm run build:site`, `npm run verify:site`. ZIP CI con imágenes, mapas de tests, resultados HTTP y capturas Chrome. `dist/` solo para web experimental, no publicado.
- CSP local y plantilla `_headers`; control `noindex,nofollow`, rutas HTTP estrictas y ausencia de formularios de pedidos/pagos.
- Los 3 perfiles sociales incluyen `data-channel-review="pending"`: **no hay prueba documental de propiedad o disponibilidad actual**. El usuario decidió posponer el canal oficial.

## B. Hallazgos confirmados y medidas adoptadas

| ID | Severidad | Observación comprobada | Estado V6.8 |
|---|---|---|---|
| A-01 | Alta | El SVG técnico mostraba `CUSTOMER`, `BUSINESS`, `RIDER` en inglés pese a la narrativa española, también en su etiqueta descriptiva. | **Corregido** en `assets/roles-geometry-es.svg`, referenciado por HTML; clientes, comercios, reparto y control. |
| A-02 | Alta | `styles.css` ocultaba toda la navegación móvil con `display:none` y el botón para abrirla requería JS. Al bloquear scripts el menú quedaba inaccesible. | **Corregido**: menú visible de forma estática y con enlaces táctiles bajo `html:not(.js-enabled)`. `app.js` aplica clase `js-enabled` SOLO después de conectar handlers de teclado/clic. |
| A-03 | Alta / integridad | Editar directamente el SVG histórico `roles-geometry-v2.svg` rompía el control de hash aprobado en `V5.5`. La primera CI detectó la regresión. | **Corregido**: original restaurado byte a byte y probado con su SHA-1 de blob Git; SVG español **nuevo**. El empaquetador no distribuye la copia original en inglés. |
| A-04 | Media / evidencia | Los mensajes de verificación describían hashes SHA-256 como «firma criptográfica». Un hash sin clave o firma no verifica autoría/autenticidad. | **Corregido** en el verificador del paquete: «archivos verificados por SHA-256, no firmados criptográficamente». |
| A-04B | Media / legibilidad | En móvil, el SVG panorámico de 720 px se reducía hasta hacer ilegibles sus rótulos, aunque las tarjetas HTML fueran legibles. | **Corregido** con `assets/roles-geometry-mobile-es.svg` dedicado (360×392), etiquetas mayores, `picture` responsive y captura Chrome que comprueba `currentSrc` y dimensiones reales. |
| A-05 | Alta / negocio | CTA de conversación termina en redes `pending`; ninguna vía de captación formal está verificada. | **Pendiente por decisión explícita**: registrar propiedad real del canal, privacidad y responsabilidad; no inventar enlaces. |
| A-06 | Alta / prueba física | WebGL CI corre con SwiftShader de software, no GPU de Android/iPhone; no prueba batería, fluidez a 30/60 FPS ni redes móviles de campo. | **Pendiente** de equipos físicos y medición p5/p50, memoria, consumo y fallbacks. |
| A-07 | Media / calidad | Tres archivos CSS de distinta generación acumulan reglas y sobrescrituras. | A-08 | Media / cobertura | Tests de Node verifican solo módulos cargados. 4 mutaciones son seleccionadas; no hay un mutation score completo ni cobertura global de código navegador. | **Pendiente**: instrumentación de bundle browser y mutation testing transversal. |
| A-09 | Media / seguridad | CI comprueba CSP, noindex, enlaces internos, HTTP loopback y versiones fijas; no hay pentest/DAST ni SCA/SAST integral. | **Pendiente** antes de producción: SBOM, dependencias transitivas, CodeQL/OSV, licencias y CSP en hosting autorizado. |
| A-10 | Media / accesibilidad | Lighthouse automático y CDP no equivalen a validación manual WCAG 2.2 con lector de pantalla, zoom 400% y teclado completo. | **Pendiente** de matriz asistiva manual y pruebas con usuarios. |
| A-11 | Media / legal | Logo, tipografías, iconos, texturas GLB y cuentas externas deben contar con titularidad y autorizaciones documentadas. | **Pendiente** de documentación de licencias/derechos y marca antes de comunicar lanzamiento. |

## C. Seguridad y cadena de suministro

- Los paquetes declarados están fijados a `three@0.187.0` y `esbuild@0.28.2`. El lockfile y el registro de instalación hacen el build reproducible a nivel de resolución de dependencias, no garantizan por sí solos ausencia de vulnerabilidades.
- Los checks no entregan secretos, ni permisos de GitHub para publicar; acciones críticas se ejecutan mediante flujo de solo lectura.
- La web experimental sigue noindex. Nunca convertir una auditoría técnica en autorización tácita de despliegue.
- **Matiz de evidencia:** `site-manifest.json` enumera SHA-256 de archivos pero **no** está firmado criptográficamente. Integridad de reconstrucción local no es autenticación de origen.
- La presencia de los tres canales `pending` no se interpreta como verificación de titularidad.

## D. Pruebas obligatorias para cierre de la intervención V6.8

1. **Compilación/paquete:** Three.js, GLB, SVG nuevo y CSS sin dependencias externas, manifiesto hash completo, SVG aprobado histórico intacto.
2. **Unitarias/contratos:** V6.8 traduce texto visible y descripción SVG, evita distribuir el original inglés, confirma CSS/JS progresivo, noindex y canales pendientes.
3. **Instrumentadas:** en Chrome CDP medir `display:flex` del menú sin clase JS y controles visibles a 390/320 px, y recuperar el estado de navegación JS. Mantener regresión de seis vistas/capturas y 32 checks WebGL en fuente y `dist/`.
4. **Cobertura/mutación:** registrar resultados de Node y cuatro mutantes dirigidos, sin extrapolación a código completo.
5. **Seguridad:** headers, rutas denegadas, CSP y ausencia de publicación automática en CI.
6. **Evidencia por SHA:** no copiar PASS de versiones anteriores. Ejecutar una CI final 2/2 sin fallos y publicar los enlaces del artefacto de auditoría, no el sitio.
7. **No-Go para publicación:** hasta aprobar el registro de canales y propiedad de marca, las licencias, pruebas de hardware real, accesibilidad manual y revisión humana.
