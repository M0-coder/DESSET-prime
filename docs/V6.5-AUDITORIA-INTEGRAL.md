## 2. Arquitectura y reproducibilidad

- Web institucional: HTML semántico, CSS, JS progresivo y sección de ecosistema. No procesa pedidos, pagos ni registra operaciones comerciales.
- Motor: Three.js 0.187.0 y esbuild 0.28.2 fijados en package-lock.json; GLB originales generados con GLTFExporter; GLTFLoader autoalojado, sin CDN.
- Construcción: npm ci --ignore-scripts, npm run build:site, verificación de dist y hashes SHA-256 de archivos.
- WebGL opt-in reduce gasto de red y GPU sin eliminar el recorrido cinematográfico ni el enlace del inicio.

## 3. Pruebas, cobertura, mutaciones e instrumentación

- Contratos: contenido, identidad, navegación, control accesible, integridad GLB, noindex, CSP, tamaño y firmas de paquete.
- Chrome CDP / SwiftShader: render 3D real, cámara, tour, pausa, imagen fallback, WebGL opt-in, tres GLB y nuevo control de tablet/cambio de dimensiones.
- Lighthouse CI: solo laboratorio de carga inicial; no representa FPS real, energía, conexiones peruanas ni INP o Core Web Vitals p75 de campo.
- Cobertura Node previa corresponde a tests y módulos importados, no es cobertura de producción/browser certificada.
- Mutation smoke: cuatro casos dirigidos, no es un score de mutation testing integral.

## 4. Análisis estático, seguridad y calidad CI

- HTML y _headers: meta robots noindex,nofollow, CSP same-origin, política sin scripts externos, controles HTTP loopback; no edición de dominios o tokens con permisos de despliegue.
- Builds desde versiones exactas y SHA de Git. Dos jobs independientes: source-check y lighthouse-local-lab, con artefactos de capturas, WebGL, bundle, GLB y dist.
- Riesgos abiertos: SAST/SCA profundo, coverage completo de JS navegador, revisión manual de accesibilidad y lector de pantalla, rendimiento en hardware real y verificación legal de recursos y de enlaces sociales marcados pending.
- Deuda técnica de diseño: CSS acumulativo V4–V6 y scripts con responsabilidades mixtas; limpieza posterior debe ser incremental con screenshots y tests, jamás borrado masivo sin evidencia.
- NO desactivar los gates de noindex o las políticas de protección para elevar un score.

## 5. Evidencia histórica y cierre

V6.4 anterior, CI 44675125404, 2/2 PASS, 76/76 Node, WebGL 27/27, 20 archivos verificados y empaquetados en dist, 1.889.123 bytes. Estos valores **no acreditan V6.5** hasta contar con ejecución propia por HEAD.
