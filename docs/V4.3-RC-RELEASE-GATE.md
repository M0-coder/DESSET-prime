## Alcance y decisión editorial

Se fija el alcance antes de proponer lanzamientos: **arquitectura, compilación, pruebas unitarias e instrumentadas, cobertura, análisis estático, calidad de CI, seguridad, reproducibilidad, mutation testing, deuda técnica y evidencia de ejecución**.

1. **Portada:** dirección cinematográfica intacta, mensaje más breve y botón principal `#contacto`; secundario `#ecosistema`. No hay pedidos falsos ni ventas en esta web.
2. **Manifiesto:** texto breve «NO ES SOLO ENTREGAR / ES CONECTAR»; retirado su listado redundante.
3. **Servicios:** pedidos/última milla como único frente visible; dos proyectos futuros solo bajo `<details class="future-services">`. La expansión no compite con el primer lanzamiento.
4. **Flujo:** se mantienen tres ilustraciones vectoriales originales y el esquema histórico opcional de cuatro participantes, sin duplicarlos en portada.
5. **Audiencias:** se mantiene la invitación a comerciantes y se condensan los perfiles de Personas/Aliados.
6. **Responsabilidad:** se retiró una sección autónoma repetitiva y se conservó el aviso de estado en el bloque de contacto y el footer.
7. **Contacto:** Instagram es el acceso visual principal **como perfil ya enlazado, pero no se ha verificado la titularidad ni capacidad de respuesta**. X y Facebook son secundarios. Los tres contienen `data-channel-review="pending"`. No se inventa correo, número de teléfono, WhatsApp o disponibilidad.
8. **CSS y JS:** revisión de clases contra DOM; sin clases huérfanas tras limpiar reglas obsoletas. `scripts/motion.js` conserva animaciones finitas, fallback sin JS y soporte `prefers-reduced-motion`.

## Matriz técnica y deuda

- **Arquitectura:** HTML/CSS/JS estáticos; sin backend ni build productivo. Corrección local reversible y enfocada.
- **Compilación:** no aplica en sentido tradicional; sí validación de sintaxis de los tres JS.
- **Pruebas unitarias:** contratos funcionales y antirregresión sobre DOM, navegación, movimiento y contenidos.
- **Pruebas instrumentadas:** navegador headless real, carga de activos, dimensiones, menú, Escape, focus, details, accesos directos, reduced motion.
- **Cobertura:** 31 tests, **sin porcentaje de cobertura certificado**.
- **Análisis estático:** pruebas estructurales y sintaxis; no SAST exhaustivo.
- **CI:** GitHub Actions pinned por SHA, permissions read-only, sin funciones de publicación.
- **Seguridad:** `noindex,nofollow`, CSP local y `_headers`; no validación HTTP real de una publicación.
- **Reproducibilidad:** SHA de código, manifest de artefacto, capturas y JSON; sin librerías remotas.
- **Mutation testing:** prueba de mutación puntual sobre menú; sin evaluación global de mutation score.
- **Deuda:** queda consolidar CSS por componentes y cotejar fuentes de marca; no reescribir sin test visual específico.
- **Evidencia:** run de CI, estado de PR y snapshots por viewport; inspección humana requerida.

## Bloqueos explícitos para GO

1. **Identidad canónica:** contrastar wordmark, tipografía, colores y composición con Figma. La API no permitió obtener estos frames por límite del plan Starter; no afirmar validación visual.
2. **Canales comerciales:** verificar **titularidad, acceso y capacidad de respuesta** de Instagram, X y Facebook y determinar canal oficial empresarial.
3. **Legal y comercial:** confirmar condición legal/registral, derechos sobre logo/activos, uso del nombre, exactitud de toda afirmación y forma de contacto institucional.
4. **Infraestructura:** GitHub `main` sigue sin protección. Definir política de status checks, review, rollback y protección de deploy; no cambiar configuración sin autorización.
5. **Pruebas faltantes:** lector de pantalla, zoom 200–400 %, navegación real, contraste integral, Core Web Vitals en móvil de gama baja, prueba HTTP CSP/headers y validación de enlaces reales.
6. **Integración:** PR #1 actualmente apunta a V3, no a `main`. Seleccionar secuencia de integración y autorización SHA explícita antes de cualquier merge/despliegue.
7. **Publicación:** mantener separados `M0-coder/DESSET-prime` y `M0-coder/DESSET`; no tocar `desset.lat`, Cloudflare, DNS, indexación o aplicaciones comerciales automáticamente.

**Decisión RC:** diseño y CI listos para revisión final. **NO merge, NO release, NO deploy, NO producción hasta el GO autorizado.**
